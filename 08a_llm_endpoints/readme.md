# Installation

In this exercise we will access language models through the [OpenAI-API](https://github.com/openai/openai-python) and subsequently a chatbot graphical user interface using [voila](https://github.com/voila-dashboards/voila). You can install both using pip:

```
pip install openai voila
``` 

For working with language models locally, download and install [ollama](https://ollama.com/).
